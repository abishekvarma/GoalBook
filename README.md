# Project Physique 40

Mobile-first personal fitness, nutrition and workout tracker. This repository is being prepared for deployment.

## Status

Source package and deployment configuration need to be added and validated before deploying. Do not treat this repository as production-ready yet.

## Planned features

- User-provided diet and workout plans
- Food and macro logging, including off-plan food tracking
- Workout sets, reps, weights and progression
- Weight and waist trends
- Daily physique photo comparisons
- Optional Supabase sync and optional server-side AI support

## Privacy and secrets

Never commit personal photos, exported health/fitness data, passwords, Supabase service-role keys, or OpenAI API keys. Any API secret must be stored as a server-side deployment environment variable.
